# منصة اللقاء التدريبي — فيديوهات المحاضرة + تقييم مجهول + لوحة تحكم

موقع بسيط وجاهز للتشغيل يعرض فيديوهات المحاضرة **داخل الموقع**، ويضم **استبيان تقييم من 10 أسئلة** (مقياس 1 – 4)
وخانة **ملاحظات نهائية اختيارية**، مع **لوحة تحكم أدمن** محمية بكلمة مرور تعرض الردود والتحليلات والرسوم البيانية وتصدير CSV.

---

## 1) التشغيل

```bash
cd lecture-site
npm install        # مرة واحدة
npm start          # ثم افتح http://localhost:3000
```

- الموقع: `http://localhost:3000`
- التقييم: `http://localhost:3000/evaluation`
- لوحة التحكم: `http://localhost:3000/admin`

### كلمة مرور الأدمن
- الافتراضية: `admin123` (تُغيَّر فورًا من ملف `config/site.json` أو بالأمر أدناه)
```bash
npm run set-password -- "كلمتك-الجديدة"
```

تظهر أسفل الفيديوهات في قسم «الأدوات التي استخدمناها في اللقاء» كبطاقات قابلة للضغط.

### أ) فيديوهات Google Drive (الطريقة المستخدمة)
1. تأكد أن المجلد/الملفات مشتركة بصلاحية **«أي شخص لديه الرابط — عارض»**، وإلا لن تُشغَّل داخل الموقع.
2. لكل فيديو أضف عنصرًا:

```json
{
  "id": "video-1",
  "title": "عنوان الفيديو",
  "description": "وصف مختصر يظهر أسفل المشغّل",
  "source": { "type": "drive", "fileId": "معرّف-الملف-من-رابط-درايف" },
  "duration": "12:40",
  "visible": true
}
```

`fileId` هو الجزء بين `/d/` و `/view` في رابط الملف:
`https://drive.google.com/file/d/`**`FILE_ID`**`/view`

### ب) ملفات MP4 مباشرة
```json
{ "id": "v1", "title": "الفيديو الأول", "source": { "type": "mp4", "url": "/media/video-1.mp4" }, "visible": true }
```
ضع الملفات في مجلد `public/media/` واستخدم مسارًا نسبيًا.

### ج) يوتيوب (اختياري)
```json
{ "id": "v1", "title": "الفيديو الأول", "source": { "type": "youtube", "videoId": "dQw4w9WgXcQ" } }
```

## 3) الاستبيان (10 أسئلة — مقياس 1 إلى 4)

| # | المحور | السؤال |
|---|--------|--------|
| 1 | المادة العلمية | مدى ملاءمة المحتوى العلمي لأهداف اللقاء واحتياجاتي التدريبية |
| 2 | المادة العلمية | وضوح المادة العلمية ودقتها وحداثتها |
| 3 | المادة العلمية | مدى ارتباط الأمثلة والتطبيقات العملية بمحتوى اللقاء |
| 4 | المادة العلمية | سهولة استخدام أدوات الذكاء الاصطناعي التي طُبِّقت خلال اللقاء |
| 5 | المدربون | تمكُّن المدربين من المادة العلمية |
| 6 | المدربون | أسلوب المدربين في الشرح وقدرتهم على إيصال المعلومة |
| 7 | المدربون | تفاعل المدربين مع المشاركين واستجابتهم للأسئلة |
| 8 | وقت التدريب | مدى مناسبة مدة اللقاء لحجم المحتوى المقدَّم |
| 9 | وقت التدريب | جودة إدارة الوقت وتوزيعه على فقرات اللقاء |
| 10 | التقييم العام | مدى استفادتي العامة من اللقاء واستعدادي لتوصية غيري به |

+ خانة **ملاحظات نهائية اختيارية** (حتى 2000 حرف).

المقياس: `1 = ضعيف جدًا` · `2 = ضعيف` · `3 = جيد` · `4 = ممتاز`

لتعديل نص الأسئلة أو ترتيبها: `server.js` → ثابت `QUESTIONS`.

**الخصوصية:** لا يُطلب الاسم أو البريد أو رقم الجوال، ولا يُخزَّن عنوان IP. الحقول المحفوظة هي الإجابات، الملاحظات، وتاريخ الإرسال فقط.

## 4) لوحة التحكم (الأدمن)

تظهر بعد إدخال كلمة المرور في `/admin`، وتحتوي:

- **مؤشرات رئيسية:** عدد الردود، متوسط التقييم العام (من 4)، نسبة التقييمات الإيجابية (3 و4)، عدد الملاحظات، متوسط زمن ملء التقييم.
- **متوسط التقييم حسب المحور:** المادة العلمية / المدربون / وقت التدريب / التقييم العام (حلقات + أشرطة).
- **توزيع الردود الزمني:** عدد الردود لكل يوم (آخر 14 يومًا).
- **تفصيل الأسئلة العشرة:** متوسط كل سؤال + توزيع الإجابات (1 – 4) + عدد الإجابات.
- **الملاحظات النهائية:** كل الملاحظات مع التاريخ ومتوسط التقييم، مع بحث فوري.
- **سجل الردود:** جدول كامل قابل للإظهار/الإخفاء، وإمكانية **حذف** أي رد.
- **تصدير CSV** (يفتح في Excel بترميز عربي سليم)، وفلاتر زمنية (كل الوقت / 7 أيام / 30 يومًا).

## 5) تخزين البيانات

**مفعّل الآن على Supabase** (مشروع `teacher-masters-supabase` → جدول `public.evaluations`):

- المفاتيح في ملف `.env` (غير مرفوع لأي مستودع، ومُدرج في `.gitignore`):
  ```
  SUPABASE_URL=...
  SUPABASE_SERVICE_KEY=...
  SUPABASE_TABLE=evaluations
  ```
- كل تقييم يُحفظ في Supabase **وأيضًا** نسخة محلية في `data/responses.json` (احتياط).
- الداشبورد يقرأ من Supabase، ولا يُخزَّن أي بيان شخصي: `id` عشوائي + الإجابات + الملاحظات + التاريخ فقط.
- سياسة RLS مفعّلة على الجدول، والكتابة/القراءة تتم من السيرفر بمفتاح `service_role` (لا يُستخدم في المتصفح إطلاقًا).
- للعمل بلا Supabase (تخزين محلي فقط): امسح/أعد تسمية ملف `.env` ثم أعد التشغيل.

## 9) ملصق QR للتقييم

- في الصفحة الرئيسية (أسفل الفيديوهات) يوجد **كود QR** جاهز لرابط التقييم، يُولَّد تلقائيًا حسب الدومين اللي الموقع شغال عليه.
- صفحة ملصق كاملة قابلة للطباعة (A4): `/qr` — فيها الكود بحجم كبير + خطوات + رابط التقييم، وزرار «طباعة».
- توزّع الملصق في القاعة أو تبعته في جروب المشاركين، وهم يمسحون الكود ويفتح معاهم استبيان التقييم مباشرة.

## 10) النشر على رابط عام (مهم)

المعاينة الحالية تعمل داخل بيئة التطوير فقط (محمية برمز وصول)، ومشاركتها مع المشاركين تحتاج نشر الموقع على استضافة عامة:

**Render (مجاني، الأسهل):**
1. ارفع مجلد المشروع إلى مستودع GitHub.
2. من Render: New → Web Service → اختر المستودع (بيتعرف على `render.yaml` تلقائيًا).
3. أضف متغيرات البيئة: `SUPABASE_URL` + `SUPABASE_SERVICE_KEY` (نفس قيم ملف `.env`).
4. بعد النشر هيوصلك رابط مثل `https://lecture-evaluation.onrender.com` — ده اللينك اللي تبعته للمشاركين، ولوحة التحكم على `/admin`.

**أو عبر Docker** (Railway / Fly.io / أي سيرفر): `docker build -t lecture-site . && docker run -p 3000:3000 --env-file .env lecture-site`

> ملف `.env` **لا يُرفع** للمستودع (مُدرج في `.gitignore`) — أضف المفاتيح يدويًا في إعدادات الاستضافة.
